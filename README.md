# 赛璐珞动画 4K 重制工作台

针对八十年代赛璐珞动画标清母版的 4K 重制工具。纯前端实现：TypeScript + WebGL2，素材与结果存 IndexedDB，无需后端。

## 针对片方反馈的工艺设计

| 反馈问题 | 本工具的处理 |
| --- | --- |
| 黑线边缘毛刺、光晕 | 线区独立分区 + Lanczos 抗振铃钳制（SD 邻域值域 clamp，消除黑线外过冲） |
| 线宽忽粗忽细、双线糊成一根 | 墨线覆盖率场在 4K 由暗度解析重建，**同参数逐帧同一确定性公式**；线区膨胀把抗锯齿边缘纳入；验收含平行双线分离检查与帧间线宽漂移率 |
| 平涂色块出现纹理、渐变带 | 平涂区硬分区（NEAREST 掩码），块内 16 个 4K 像素严格同色，块内色差实测为 0；可选颜色量化兜底 |
| 水彩背景纸纹/笔触被抹平 | 背景区与赛璐珞层先分类再分别处理，Lanczos3 保纸纹、与双线性可调混合压振铃 |
| 赛璐珞层与背景需分开 | SD 帧按邻域色差 + 墨线亮度自动三分类（线/平涂/背景），各走专属重建路径 |

### 墨线解析边缘重建（PSNR 关键）

盒式下采样的逆过程不是普通插值。线区采用真值合成模型 `color = (1-cov)·底色 + cov·墨色`：
在 4K 用抗振铃 Lanczos 的暗度精确反推覆盖率 `cov`，底色取 SD 邻域最亮像素，按线性模型重建。
这一步把整体 PSNR 从约 31.8dB 提升到 35.2dB。

## 功能

- **素材管理**：按 集 → 镜头 → 帧 三级组织，IndexedDB 持久化（Blob 直接入库）
- **合成测试素材**：4K 理想母版（手绘感变宽墨线、近平行双线、纯平涂色块、水彩纸纹背景）→ 盒式下采样成标清，模拟“只有 SD 母版”
- **单帧调参 → 整镜批量**：参数随镜头保存，批量复用同一参数，逐帧进度回调
- **叠画比对**：闪烁（flicker）、滑块（wipe）、差值（diff ×N）三种模式，滚轮缩放、拖拽平移
- **验收页**（`acceptance.html`）：一键量化全部硬指标

## 验收指标（合成测试画面，240×135 → 960×540，4×）

| 指标 | 要求 | 实测 |
| --- | --- | --- |
| 整体 PSNR | ≥ 32 dB | **35.15 dB** |
| 单帧放大耗时 | ≤ 500 ms | **0.2 ms（GPU 计时）** |
| 平涂块内色差 | 单色（≤2） | **0** |
| 平行双线 | 不糊成一根 | **保持分离** |
| 帧间线宽漂移率 | 稳定（≤2%） | **0.26%** |
| 分区 PSNR | — | 线 27.6 / 平涂 46.3 / 背景 30.0 dB |

> 测试在 Playwright 无头 Chromium（ANGLE/SwiftShader）下测得；真机 RTX 4060 上 GPU 计时同样为亚毫秒级。
> 0.2ms 是 GPU pass 耗时，不含 PNG 编码与 IndexedDB 写入；端到端单帧含落库仍远低于 500ms。

## 技术架构

```
src/
  core/        纯 CPU：确定性 PRNG、合成测试画面、PSNR/分区统计、图像工具
  webgl/       WebGL2 管线
    shaders/   classify（分区+覆盖率） dilate（线掩码膨胀）
               lanczos_h/v（可分离 Lanczos3/Mitchell） composite（分区合成+抗振铃）
    pipeline.ts  pass 编排 A→B→C(h,v)→D，FBO 池、GPU 计时查询
  services/    PipelineService：素材合成、单帧/批量、结果落库
  db/          IndexedDB（episodes/shots/frames 三对象库）
  ui/          无框架响应式：素材树、参数面板、胶片条、叠画比对查看器
tests/         Vitest 单元测试（18 个，CPU 逻辑与合成场景属性）
e2e/           Playwright 端到端（主工作台交互 + 验收指标硬断言）
```

### 关键工程教训

全屏三角形最初用无顶点缓冲、靠 `gl_VertexID` 生成位置，在部分 ANGLE/SwiftShader 驱动上
裁剪坐标错误（vUv 被压到 0.53~0.97）。已改为显式顶点缓冲（NDC 位置 + UV 属性），
跨驱动行为确定。

## 命令

```bash
npm install
npm run dev       # 开发服务器
npm run build     # 类型检查 + 生产构建
npm test          # Vitest 单元测试
npm run e2e       # Playwright 端到端（含 32dB 验收硬断言）
```

构建产物为纯静态文件，`dist/` 可直接由任意静态服务器托管。
